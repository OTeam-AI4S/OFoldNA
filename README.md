# OFoldNA

Official repository for **Leveraging secondary-structure information for accurate nucleic acid structure prediction with OFoldNA**.

OFoldNA is an all-atom diffusion model for nucleic acid folding and protein–nucleic acid co-folding. It learns base-pairing relationships internally and supports prediction with absent, partial or complete external secondary-structure information.
